说明

OpenOCD-GUI 是 OpenOCD 的图形前端：负责拼出 OpenOCD 命令行、管理 OpenOCD 进程、通过 TCL 端口读写目标状态（目标 / 寄存器 / 内存 / 断点 / 烧写）。真正的调试协议与 flash 算法都来自 OpenOCD 本体；GDB 与编译器不由本项目提供。
